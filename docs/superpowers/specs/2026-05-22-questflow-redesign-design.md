# QuestFlow — Design Spec: Полный редизайн + инфраструктура
**Дата:** 2026-05-22  
**Статус:** Approved  
**Версии:** v3.2.0 → v4.0.0

---

## 1. Контекст и цель

QuestFlow «Хроники Судьбы» — PWA-планировщик в стиле Ведьмак/Dark Souls. Текущая версия v3.2.0 имеет дизайн-систему v3 «Кодекс Охотника» (пергамент + золото + сургуч), но только главный экран квестов переделан в новом стиле. Остальные 10 экранов — в старом тёмно-синем Dragon Age стиле. Это рвёт атмосферу.

**Цель:** Привести все экраны к единому v3-стилю + добавить AI-фоны с параллаксом + починить календарь + запустить бэкенд для автогенерации квестов.

---

## 2. Приоритет и порядок работ

**Принцип:** Сначала красота, потом инфраструктура. Экран за экраном — после каждого можно деплоить.

- `bg-dungeon.jpg` — каземат с факелами
- `bg-hero-hall.jpg` — зал доспехов
- `bg-library.jpg` — библиотека
- `bg-projects.jpg` — стол с картой
- `bg-shop.jpg` — лавка алхимика
- `bg-calendar.jpg` — обсерватория

### Нужно сгенерировать
- `bg-routines.jpg` — монастырский дворик / часовня со свечами
- `bg-archive.jpg` — подвал с гримуарами и пыльными свитками
- `bg-stats.jpg` — башня мага с астролябиями и картами звёздного неба
- `bg-bestiary.jpg` — скрипторий с рукописями и чернилами

### Визуальная интеграция
- Тип: параллакс + размытие (CSS `filter: blur(2px)`, `transform: translateY(var(--parallax-offset))`)
- Оверлей: 55% тёмного градиента снизу чтобы контент читался
- Фон крепится к верхней части экрана (первые ~300px), далее плавный переход в `--bg` (#0a0706)
- На мобиле: параллакс отключается, просто blur-фон

## 4. Блок 1 — Редизайн экранов

### Порядок (от самого посещаемого)
1. Подземелье
2. Персонаж
3. Обряды
4. Журнал
5. Архив
6. Проекты
7. Статистика
8. Лавка
9. Бестиарий

### Общие принципы для каждого экрана
- Параллакс-фон из `assets/web/`
- Шапка экрана: пергаментная полоса с названием в стиле «CAPITULUM N — НАЗВАНИЕ»
- Карточки: clip-path рваные края, тёплый пергаментный фон `#f4e8c8`→`#d8c498`
- Кнопки: медная рамка `--bdg`, hover — gold glow
- Текст на тёмном фоне: кремовый `--text` (#ead5a4)
- Текст на пергаменте: коричневый `#3a2010`
- Разделители: двойная золотая линия

### Специфика по экранам

**Подземелье:**
- Большая карточка врага (портрет + имя + HP-бар в стиле DS)
- Кнопки атак — пергаментные таблички с рунами
- Лог боя — свиток разворачивается снизу

**Персонаж:**
- Большой портрет героя из `assets/web/p0X.jpg` слева
- Статы — стилизованные свитки с заполнением
- Снаряжение — сетка ячеек как инвентарь в DS

**Обряды:**
- Список рутин — каждая как пергаментная строка с чекбоксом-печатью
- Heatmap по дням недели — 7 ячеек, заливка золотом при выполнении

**Журнал:**
- Таймлайн с минутами — вертикальная линия слева, события справа
- Иконки категорий — медальоны

**Архив:**
- «Свод суждений» — статистика по рангам S/A/B/C/D с сургучными печатями
- Список с пергаментными строками, фильтры по категории

**Проекты:**
- Сетка 2×2 пергаментов
- Прогресс-бар в виде свитка (разворачивается по мере выполнения)

**Статистика:**
- Большой график продуктивности в пергаментной рамке
- Heatmap активности по дням
- Блок достижений — золотые медальоны

**Лавка:**
- Сетка предметов — натюрморты как в таверне
- Цена — монеты с иконкой

**Бестиарий:**
- Сетка карточек монстров с иллюстрациями
- Фильтры по типу + поиск
- Карточка: пергамент с описанием, статами, слабостями

## 5. Блок 2 — Переделка календаря

### Проблемы (все подтверждены)
- Занимает слишком много места
- Неудобно добавлять события
- Плохо видно что запланировано
- Не связан с квестами
- Нет фэнтезийного духа

### Решение
**Дефолтный вид: компактная неделя**
- Показываем текущую неделю (7 дней) горизонтально в верхней части
- Под каждым днём — список квестов с дедлайном + события
- Переключатель: Седмица / Луна (неделя / месяц)
- Стиль: «ТРАВЕНЬ, СЕДМИЦА III, MMXXVI»

**Быстрое добавление:**
- Клик по дню → inline-форма появляется прямо под ним (не модалка)
- 2 поля: название + время. Готово

**Квесты в календаре:**
- Квесты с дедлайнами автоматически видны в соответствующих днях
- Цвет = цвет категории квеста (work/study/health/hobby/life)

**Месячный вид:**
- Компактная сетка 7×5, каждый день — маленькая точка или полоска
- Клик по дню — разворачивает детали внизу (не отдельный экран)

## 6. Блок 3 — Бэкенд + Claude API

### Архитектура
- **Cloudflare Workers** — бессерверный прокси (бесплатный tier: 100k запросов/день)
- Хранит API-ключ Anthropic в environment variables (не в коде)
- Эндпоинт: `POST /api/generate-quest` → возвращает `{title, description}`
- Rate limiting: 20 запросов/день на IP (защита от злоупотреблений)

### Модель
- **Claude Haiku 3.5** — самая дешёвая, достаточно умная для 2-3 предложений
- Prompt caching для системной инструкции (экономия ~60%)
- Ожидаемая стоимость: ~$1-2/день при 1000 активных пользователях

### Промпт-стиль
Система: «Ты писарь охотника на чудовищ в мире тёмного фэнтези. Пиши в духе Ведьмака. Краткие, атмосферные названия и описания заданий.»
Пользователь: `{категория}: {исходное название задачи}`

## 7. Блок 4 — Авторизация

- Firebase Auth — Google Sign-In (уже частично настроено в коде)
- При первом входе: привязать существующий localStorage к аккаунту
- Firestore sync — Last-Write-Wins (уже реализован в v2.3.0)
- На экране персонажа: аватар Google, имя, кнопка выхода

## 8. Блок 5 — Безопасность + App Store

- HTTPS everywhere (Netlify → уже есть)
- CSP headers в netlify.toml
- Нет чувствительных данных в localStorage (пароли/платёжные данные отсутствуют)
- Capacitor wrapper для iOS/Android
- Privacy Policy страница (требование App Store)

---

## 9. Технические ограничения

- **Никаких внешних шрифтов** — Google Fonts ломают PWA offline
- **Никаких внешних библиотек** — всё inline в одном HTML файле
- **После каждого JS-изменения:** `node --check` синтаксиса
- **Рабочий процесс:** `files/questflow.html` → `cp` → `index.html` → деплой
- **Версия:** бампить в 3 местах + CACHE_NAME в service-worker.js

## 11. Критерии готовности

- [ ] Все 10 экранов в v3-стиле, единый визуальный язык
- [ ] Параллакс-фоны работают на десктопе, graceful fallback на мобиле
- [ ] Календарь: компактный вид недели, квесты видны в днях, быстрое добавление
- [ ] Генерация квестов работает без ввода API-ключа
- [ ] Google Sign-In работает
- [ ] Приложение проходит базовый security audit
